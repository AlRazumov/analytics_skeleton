# Этап 26: переключатель месяцев на страницах — отчёт

## 1. Что сделано

«← 2026-07 · **2026-08** · 2026-09 →» над обзором, топом товаров,
категориями, остатками, оборачиваемостью, перемещениями и продавцами.

| Слой | Файл | Что |
|---|---|---|
| widgets (контракт) | `Core/Widgets/Contracts/MetricsComparisonRepository.php` | `adjacentPeriods(list<[entity_type, metric_key]>, Period)` — ближайшие периоды с данными до и после |
| репозитории | `EloquentMetricsComparisonRepository` | два запроса `MAX(period_start) < …` / `MIN(period_start) > …` по парам сущность+метрика |
| widgets | `Core/Widgets/MonthNavigationProvider.php`, `DTO/MonthNavigation.php` | навигация для показанного месяца |
| presentation | контроллеры семи страниц, `components/widgets/month-switcher.blade.php`, шаблоны, стиль в `standalone.blade.php` | ссылки через `fullUrlWithQuery` — остальные параметры запроса сохраняются |
| docs | `docs/demo.md` | как переключать месяц |

## 2. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Какой месяц «текущий» | тот, что страница уже определила сама (запрошенный или последний с данными её метрики) | логика «последнего периода» не дублируется, переключатель всегда совпадает с тем, что на странице |
| Куда ведут ссылки | в ближайший месяц, за который есть снэпшоты метрик страницы, а не просто ±1 месяц | не ведут на пустую страницу; пропуски в данных перескакиваются |
| Метрики страниц | обзор и топ — `product/revenue`; категории — `category/revenue`; остатки — `product/days_since_last_sale` и `product_warehouse/days_of_stock`; оборачиваемость — `product/turnover`; перемещения — `product_warehouse/days_of_stock`; продавцы — выбранная метрика `seller/*` | пары, а не только metric_key: `revenue` есть и у товаров, и у категорий |
| Параметры страницы | сохраняются (`category`, `base`, `metric`) | переключение месяца не должно сбрасывать фильтр |
| ABC/XYZ | без переключателя | классификация пишется за один (последний) период расчёта |
| Подпись | ключ `YYYY-MM`, как в остальных подписях периода | единообразно; русские названия месяцев — отдельной правкой по всем страницам, если понадобится |

## 3. Тесты

`tests/Feature/Dashboards/MonthSwitcherTest.php`:

- `adjacentPeriods`: пропуски перескакиваются, крайние месяцы — null,
  несколько метрик объединяются, та же metric_key у другой сущности не в счёт;
- на каждой из семи страниц (Small-мок, июнь–август): на последнем месяце —
  ссылка на предыдущий и нет «следующего», на первом — наоборот;
- ссылки сохраняют `base`, `category` (топ) и `metric` (продавцы);
- без данных и на ABC/XYZ переключателя нет.

Полный прогон (включая slow), Pint и PHPStan — зелёные.
