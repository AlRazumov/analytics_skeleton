# Этап 21: CSV-выгрузка табличных страниц — отчёт

## 1. Что сделано

| Страница | Выгрузка | Что внутри | Имя файла |
|---|---|---|---|
| Топ товаров | `/dashboards/top-products/export` | все товары с выручкой за месяц, по убыванию; `?base=previous\|year_ago` | `top-products-YYYY-MM[-year-ago].csv` |
| Категории | `/dashboards/categories/export` | таблица категорий с долей, базой и дельтами; `?base=` | `categories-YYYY-MM[-year-ago].csv` |
| Остатки | `/dashboards/stock/export/dead-stock` | все неликвиды (`days_since_last_sale >= dead_stock_display_days`) | `dead-stock-YYYY-MM.csv` |
| Остатки | `/dashboards/stock/export/stockout-risk` | все пары товар × склад с `days_of_stock <= stockout_risk_days` | `stockout-risk-YYYY-MM.csv` |
| Оборачиваемость | `/dashboards/turnover/export` | все товары, по возрастанию оборачиваемости | `turnover-YYYY-MM.csv` |
| Перемещения | `/dashboards/transfers/export` | все рекомендации | `transfers-YYYY-MM.csv` |

У всех: `?period=month:YYYY-MM` (иначе последний период метрики; невалидный —
404), вход обязателен, флаг — тот же, что у таблицы (у остатков — свой у
каждой выгрузки), 404, если расчёт метрики ещё не выполнялся. Ссылка
«Скачать CSV» — под таблицей; в ней уже определённый период таблицы, так что
файл совпадёт со страницей, даже если между просмотром и кликом прошёл расчёт.

## 2. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Сколько строк | все, а не `display.table_limit` | на странице 20 строк из тысяч; выгрузка нужна именно для полного списка |
| Лимит репозитория (1..1000) | `top()` принимает `limit = null` — без LIMIT; явный лимит по-прежнему проверяется | на Large 5000 товаров; отдельный метод дублировал бы запрос |
| Топ и анти-топ, низкая и высокая оборачиваемость | один файл на страницу, полный список в одном порядке | анти-топ — хвост того же списка; два файла с пересечением только путают |
| Колонки | как на странице, плюс «#» и идентификаторы (товара, склада, категории) | идентификатор нужен, чтобы сопоставить строку с учётной системой |
| Точность | как на странице (`Format::num` в шаблонах) | чтобы числа в файле и на экране совпадали |
| Пустые значения | пустая ячейка вместо «—» | в числовой колонке «—» Excel прочитает как текст |
| «≥» у неликвидов без продаж за всю историю | отдельная колонка «Без продаж за весь просмотренный период» (да/нет) | число дней остаётся числом |
| Бесконечное покрытие донора без продаж | пустая ячейка (на странице «—») | `INF` в CSV бессмысленен |
| Названия для 5000+ id | резолверы товаров и складов ищут порциями по 10 000 | у Postgres не больше 65 535 параметров в запросе; без порций выгрузка большого справочника падала бы (проверено тестом) |
| Общий код | `Support/Csv` (BOM, `;`, числа), `Support/TableCsv` (колонки страниц), трейт `RespondsWithCsv` (заголовки ответа, имя файла, 404 без данных); `TopNCsv` и выгрузка продавцов переведены на них | формат и заголовки у всех выгрузок одни |

Строится в памяти, без стриминга: на Large (см. §4) это до 37 МБ пика.
Если реальный клиент окажется на порядок больше, можно перейти на
`streamDownload` с курсором, не меняя формат.

## 3. Файлы

- `app/Support/Csv.php`, `app/Support/TableCsv.php` — новые; `TopNCsv.php` — на `Csv`.
- `app/Http/Controllers/Dashboards/RespondsWithCsv.php` — новый; `export`-методы
  в контроллерах топа, категорий, остатков, оборачиваемости, перемещений;
  продавцы — на трейте.
- `app/Core/Widgets/Contracts/MetricsComparisonRepository.php`,
  `app/Repositories/EloquentMetricsComparisonRepository.php` — `?int $limit`.
- `app/Core/Widgets/ProductTablesProvider.php`, `app/Services/TransferTableProvider.php`
  — `?int $limit` (null — все строки).
- `app/Repositories/DbProductNameResolver.php`, `DbWarehouseNameResolver.php` — порции.
- `routes/web.php`, шаблоны страниц — маршруты и ссылки.
- Доки: `features.md`, `demo.md`, `security.md`, `README.md`.

## 4. Проверка

Тесты:

- `tests/Feature/Dashboards/CsvExportTest.php` — гость → `/login`; до расчёта
  → 404; флаги; невалидные `?period`/`?base` → 404; для каждой выгрузки —
  заголовки колонок, число строк = `total` страницы при `table_limit` 1–3,
  совпадение первых строк со страницей, порядок, пороги остатков, пустые
  ячейки у базы «год назад» и у покрытия донора без продаж, имя файла;
  выгрузки не обращаются к адаптеру.
- `EloquentMetricsComparisonRepositoryTest` — `top()` с `limit = null` отдаёт
  1001 строку.
- `NameResolversTest` — 70 000 id за один вызов (без порций — `number of
  parameters must be between 0 and 65535`).
- `tests/Unit/Support/CsvTest.php` — числа, null/INF, BOM, экранирование.

Полный прогон: 566 тестов зелёные (включая `slow`), Pint и PHPStan (уровень 8)
чистые.

Замер на Large-профиле (БД `perf`, расчёт 2025-09..2026-08, второй запрос):

| categories | 4 мс | 5 | 1 КБ | 34 МБ |

«Строк» — строки файла без заголовка.

## 5. Не сделано

- Выгрузка обзора и ABC/XYZ — это сводки; если понадобится, ABC/XYZ-класс
  разумнее добавить колонкой в выгрузку топа товаров.
- xlsx — не нужен, пока CSV открывается в Excel без мастера импорта.
- Фильтр `?category=` — следующий пункт roadmap (продолжение этапа 20); у
  выгрузок он должен появиться вместе со страницами.
