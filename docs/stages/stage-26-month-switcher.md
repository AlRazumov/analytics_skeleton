# Этап 26: переключатель месяцев на страницах

Идея из «Следующих шагов» roadmap (п. 4); закрывает вопрос 1 отчёта этапа 14
(`reports/stage-14-transfer-recommendations.md`, §10). Зависит от этапа 22
(параметры страниц `?category=`), реальные адаптеры не нужны.

## Что делаем

- Над каждой страницей с месяцем (обзор, топ товаров, категории, остатки,
  оборачиваемость, перемещения, продавцы) — «← предыдущий · текущий ·
  следующий →».
- Соседние месяцы — ближайшие, за которые есть снэпшоты метрик этой страницы
  (пропуски перескакиваются); у крайних месяцев ссылки в ту сторону нет.
- Остальные параметры страницы (`category`, `base`, `metric`) сохраняются.
- Без JS; данные только из БД.

## Что не входит

ABC/XYZ (классификация за один период), выбор месяца из списка, переключение
на неделях/кварталах.

Детали и результаты — `docs/reports/stage-26-month-switcher.md`.
