# Этап 06: контракты движений/остатков, Period, metrics_snapshots, MockAdapter (часть 1)

Нумерация: реальные адаптеры (бывшие 06/07) сдвинуты (сейчас 09/10) — они
отложены на неопределённый срок (решение владельца проекта,
2026-09-19), а этот этап логически предшествует им.

## Что делаем

Готовим контракты под метрики, которым нужна история движений и
остатки на дату (неликвиды, дни до обнуления, PoP/YoY), и мок,
достаточно реалистичный для проверки этих метрик по эталону.

## Что входит

1. `StockMovement` (тип-enum, количество со знаком, парные перемещения),
   `StockBalance`.
2. `DataSourceAdapter`: `fetchStockMovements`, `fetchStock(?asOf)`,
   `capabilities()`; enum `AdapterCapability`.
3. Value object `Period` (day/week/month/quarter/year, канонические
   ключи); прежний `Period` переименован в `PeriodRange`.
4. `metrics_snapshots`: `period` → `period_type`/`period_start`/
   `period_end`, уникальный индекс и индекс под топ/анти-топ.
5. `MockAdapter`: детерминированная история, согласованные остатки,
   шесть сценариев, манифест эталонных фактов.

## Что не входит

Сами метрики, авторизация, флаги, реальные адаптеры, виджеты.

Детали, принятые решения и результаты — `docs/reports/stage6-part1.md`.
