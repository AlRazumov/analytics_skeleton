# Этап 12: витрина на моке — графики, оборачиваемость, YoY, демо-режим

Зависит от этапов 09–11. Реальные адаптеры сдвинуты на 13/14. Цель — довести
продукт до показываемого состояния на данных MockAdapter.

## Что делаем

**A. Оборачиваемость.** Страница `/dashboards/turnover`, флаг `turnover`,
пункт навигации: таблицы «Самая низкая/высокая оборачиваемость» и график
распределения по корзинам.

**B. Графики новых метрик.** Неликвиды по возрасту, дни до обнуления, топ-N
выручки; проверка графика динамики на overview. Корзины считаются агрегатом
в SQL (`MetricsComparisonRepository`).

**C. YoY.** Переключатель базы сравнения на `/dashboards/top-products`
(`?base=previous|year_ago`).

**D. Демо-режим.** Команда `demo:install`, `docs/demo.md`, удаление
`/demo/widgets`.

**E. Проверка целостности демо.** Feature-тест: `demo:install` на Small →
все страницы отвечают 200 с данными и графиками, рендерятся без адаптера.

## Что не входит

Изменения `metrics_snapshots`, калькуляторов, контракта `DataSourceAdapter`,
данных и сценариев мока; деньги, роли, IframeLayout, iframe-роуты, реальные
адаптеры, Pennant и другие пакеты, рекомендации перемещений, прогноз, алерты.

Детали и результаты — `docs/reports/stage-12-showcase.md`.
