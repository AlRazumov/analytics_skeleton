# Этап 08: правки метрик остатков, сравнение периодов, топ/анти-топ

Зависит от этапов 06 и 07. Реальные адаптеры сдвинуты на 10/11.

## Что делаем

**A. Правки метрик остатков** (по итогам этапа 07): согласование
числителя и знаменателя `days_of_stock`; lookback для неликвидов;
период по умолчанию `metrics:calculate` для мока; актуализация докблока
`MetricsCalculationService`.

**B. Слой запросов** поверх `metrics_snapshots` (таблица и калькуляторы
не меняются): сравнение периодов (`Previous` / `YearAgo`) JOIN-ом по
точному ключу периода и топ/анти-топ по значению или дельте с сортировкой
и LIMIT в SQL.

**C. Аудит `TurnoverCalculator`** — только описание в отчёте, код не
меняется.

## Что не входит

Изменение `metrics_snapshots`, виджеты, презентационный слой, прогноз,
алерты, реальные адаптеры.

Детали и результаты — `docs/reports/stage-08-period-comparison.md`.
