# Этап 29: пороги аналитики в `.env`

Запрос владельца (2026-09-28): подкручивать пороги (например, 20 шт. у донора
без продаж) на разных проектах без правки кода. Реальные адаптеры не нужны.

## Что делаем

- Все числовые пороги `config/analytics.php` (`stock`, `lost_sales`,
  `transfers`, `display`) — переменные `.env` со строгим разбором
  (`App\Support\EnvNumber`): пусто — прежнее значение по умолчанию, мусор или
  значение вне диапазона — ошибка с именем переменной при загрузке конфига.
- Списки границ корзин графиков — через запятую.
- `docs/features.md`: колонка «Env» во всех таблицах порогов, как применить
  на сервере; `.env.example` — основные переменные.

## Что не входит

Реестр и список включённых метрик продавцов, колонки топ-N (не пороги, а
состав метрик); проверка согласованности порогов перемещений при загрузке
конфига (её делает планировщик).

Детали и результаты — `docs/reports/stage-29-config-env.md`.
